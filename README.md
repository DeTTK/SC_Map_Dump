# SC Map Dump

Экспорт выбранных чанков игрового `map_cache` в Blender.

Поддерживаются:

- старый формат MDAT 5.0;
- формат MDAT 6.0 с terrain-данными и кешем объектов (object blob сохраняется и переносится вместе с чанком, но намеренно не резолвится в игровые меши);
- оптимизированная блоковая геометрия, CTM-текстуры, маскируемые и невидимые блоки;
- выбор чанков и исключение отдельных world-каталогов через web-интерфейс.

## Запуск

```powershell
pip install -r requirements.txt
python mdat_app.py
```

Откройте <http://127.0.0.1:39300/>, укажите папку игры, выберите чанки и запустите экспорт. Приложение автоматически выбирает самую новую числовую версию внутри `map_cache` (например, `6.0`).

Для текстур блоков используются файлы из `<game>\modassets\assets`, а локальные таблицы геометрии лежат в `assets/configs` репозитория.

Каждый экспорт создаёт отдельную папку в `exports/` с `.glb`, `.blend` и `job.json`.

Объекты из MDAT 6.0 не восстанавливаются в сцену: числовые object ID зависят от версии игрового реестра. Поддержка 6.0 здесь означает корректное чтение и фильтрацию кеш-файлов для terrain-экспорта.

# SC Map Dump

Приложение для экспорта mdat файлов в blend сцену как 3D модель.

## Запуск

```powershell
pip install -r requirements.txt
python mdat_app.py
```

Интерфейс приложения в браузере по адресу <http://127.0.0.1:39300/>.
Задаёте настройки, выбираете нужные чанки и конвертируете.

Приложение экспортирует только ту информацию, что есть в mdat файлах: это чанки с блоками.
Достать карту вместе с расставленными объектами не вмешиваясь в работу игры невозможно, поэтому карты с расставленными объектами я делаю по запросу, пишите в личку Telegram [@TeamDima](https://t.me/TeamDima)

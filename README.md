# SC Map Dump

Приложение для экспорта mdat файлов в blend сцену как 3D модель.

## Запуск

```powershell
pip install -r requirements.txt
python mdat_app.py
```

Интерфейс приложения в браузере по адресу <http://127.0.0.1:39300/>.
Задаёте настройки, выбираете нужные чанки и конвертируете.
